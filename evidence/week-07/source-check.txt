========================================
1. ROUTE
========================================
File: routes/web.php

Route utama:
Route::get('/', [HomeController::class, 'index'])
    ->name('home');

Pemeriksaan:
- URL utama: /
- HTTP method: GET
- Nama route: home
- Controller: HomeController@index

========================================
2. CONTROLLER
========================================
File:
app/Http/Controllers/HomeController.php

Pemeriksaan:
- Menyiapkan nama website KursusKu.
- Menyiapkan daftar kursus dalam array.
- Mengirim data ke view home menggunakan compact().

========================================
3. VIEW BLADE
========================================
File: resources/views/home.blade.php

Pemeriksaan:
- Menggunakan Blade untuk menampilkan halaman.
- Menampilkan daftar kursus menggunakan @foreach.
- Memanggil CSS dan gambar menggunakan helper asset().

========================================
4. PUBLIC ASSETS

public/css/style.css

public/images/hero-kursus.png

Pemeriksaan:

- Tampilan browser digunakan untuk memeriksa hasil halaman.

Perintah:
