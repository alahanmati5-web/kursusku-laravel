# AI Usage Log — Praktikum Laravel KursusKu

## 1. Tujuan Penggunaan AI
AI digunakan sebagai alat bantu belajar dalam proses pengembangan project KursusKu menggunakan framework Laravel.

## 2. Bentuk Bantuan AI
- Membantu memahami konsep MVC pada Laravel.
- Membantu memeriksa route, controller, dan Blade view.
- Membantu menjelaskan cara menjalankan aplikasi Laravel.
- Membantu menyusun diagram request lifecycle.
- Membantu memberikan panduan pengujian dan dokumentasi project.
- Membantu menyiapkan daftar bukti praktikum.

## 3. Peran Mahasiswa
Mahasiswa menjalankan perintah pada terminal, memeriksa hasil aplikasi, mengelola file project, dan melakukan pengujian secara langsung.

## 4. Verifikasi
Saran dari AI diperiksa kembali melalui kode project, terminal, dan browser. Hasil akhir tetap perlu diuji untuk memastikan aplikasi berjalan dengan benar.

## 5. Pernyataan
AI digunakan sebagai alat bantu pembelajaran, bukan sebagai pengganti pemahaman dan tanggung jawab mahasiswa terhadap project yang dikerjakan.
