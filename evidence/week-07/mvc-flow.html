Alur MVC Laravel — KursusKu

Alur permintaan pengguna dari Route hingga halaman KursusKu ditampilkan di browser.

1. Browser / Request

Pengguna membuka halaman utama melalui URL /.

↓

2. Route

routes/web.php

Route bernama home mengarah ke HomeController.

↓

3. Controller

HomeController@index

Menyiapkan nama website dan daftar kursus.

↓

4. Data

Data kursus disiapkan dalam array pada controller.

Project ini menggunakan data array, bukan Model database untuk daftar kursus.

↓

5. View (Blade)

resources/views/home.blade.php

Menampilkan data menggunakan Blade, termasuk @foreach.

↓

6. HTML Response

Laravel mengirimkan hasil tampilan halaman kepada browser.

Komponen pendukung:
  • CSS: public/css/style.css
  • Gambar: public/images/hero-kursus.png
  • Framework: Laravel 13
Catatan: data kursus saat ini disiapkan langsung di controller, sehingga diagram ini tidak mengasumsikan adanya Model atau database khusus untuk data kursus.
