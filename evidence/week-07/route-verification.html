Route Verification — KursusKu

Dokumentasi pemeriksaan route dan komponen Laravel MVC.

1. Informasi Project

Framework: Laravel 13.38.0
PHP: 8.4.27
Branch Git: main

2. Konfigurasi Route

File: routes/web.php

Route::get('/', [HomeController::class, 'index'])
    ->name('home');

Route utama menggunakan metode GET, menerima permintaan ke halaman /, dan memanggil HomeController@index.

3. Controller

File: app/Http/Controllers/HomeController.php

  • Menyiapkan nama website KursusKu.
  • Menyiapkan daftar kursus dalam array.
  • Mengirim data ke view menggunakan compact().

4. View dan Asset

  • Blade: resources/views/home.blade.php
  • CSS: public/css/style.css
  • Gambar: public/images/hero-kursus.png
  • Daftar kursus ditampilkan menggunakan @foreach.

5. Perintah Verifikasi

php artisan route:list

Perintah ini digunakan untuk memeriksa daftar route yang terdaftar di aplikasi Laravel.

Catatan: halaman ini merupakan dokumentasi pemeriksaan. Untuk bukti hasil eksekusi, gunakan screenshot terminal yang menampilkan output perintah sebenarnya.

6. Ringkasan

Berdasarkan pemeriksaan kode project, route utama terhubung ke controller dan controller mengirim data ke view Blade. Keberhasilan runtime tetap dibuktikan melalui pengujian aplikasi dan output terminal.
