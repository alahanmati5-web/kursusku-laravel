Project Laravel KursusKu — Praktikum Week 7

1. Route

Lokasi: routes/web.php

Route::get('/', [HomeController::class, 'index'])
    ->name('home');

Route utama mengarahkan permintaan halaman beranda ke HomeController.

2. Controller

Lokasi: app/Http/Controllers/HomeController.php

  • Menetapkan nama website KursusKu.
  • Menyiapkan data daftar kursus dalam array.
  • Mengirim data ke view menggunakan compact().
return view('home', compact('namaWebsite', 'kursus'));

3. View Blade

Lokasi: resources/views/home.blade.php

  • Menampilkan data yang dikirim oleh controller.
  • Menggunakan @foreach untuk daftar kursus.
  • Menggunakan helper asset() untuk CSS dan gambar.
@foreach ($kursus as $item)
    ...
@endforeach

4. Asset Publik

CSS: public/css/style.css

Gambar: public/images/hero-kursus.png

Asset digunakan untuk mendukung tampilan halaman utama KursusKu.

5. Pemeriksaan

php artisan route:list

Perintah ini digunakan untuk melihat route yang terdaftar pada aplikasi Laravel.

Halaman ini merupakan dokumentasi source code. Untuk bukti autentik, gunakan screenshot editor yang menampilkan kode sebenarnya serta screenshot terminal hasil pengujian.

Kesimpulan

Struktur project KursusKu menerapkan alur Laravel MVC: route menerima request, controller menyiapkan data, dan view Blade menyajikan halaman kepada pengguna.
