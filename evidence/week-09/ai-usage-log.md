## Catatan Penggunaan AI

Selama mengerjakan tugas Week 9, saya menggunakan AI sebagai alat bantu untuk memahami dan menyelesaikan beberapa bagian pengembangan aplikasi KursusKu.

Beberapa bantuan yang digunakan antara lain:

1. Membantu memahami penerapan Bootstrap dan jQuery pada Laravel.
2. Membantu menyusun layout Blade dan partial navbar.
3. Membantu memperbaiki tampilan halaman agar tetap mempertahankan desain hijau neon KursusKu.
4. Membantu membuat fitur pendaftaran praktikum.
5. Membantu menerapkan pengecekan sisa kuota kursus menggunakan AJAX.
6. Membantu memeriksa route dan pengujian respons JSON melalui Developer Tools.
